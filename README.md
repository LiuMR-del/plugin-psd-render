# plugin-psd-render — PSD 模版批量生图

在装有 Photoshop 的机器上本地运行的桌面小工具：读取 Excel，按 SKU 找到对应 PSD 模版，驱动 Photoshop 替换文字图层后批量导出 PNG。文字替换走 Photoshop 原生渲染，**100% 保真**（自动重排、字距、样式全保留）。

**安装与更新**：把 [AI安装与更新指令.md](AI安装与更新指令.md) 里对应的一段复制给 AI 编程助手即可（首次安装 / 更新 / 发布更新）。照着做的精简步骤见 [操作步骤.txt](操作步骤.txt)，部署和日常操作的完整说明见 [使用说明.txt](使用说明.txt)。

- 双平台：渲染业务逻辑写在一份 `render.jsx`（两平台同一 JSX 引擎），Windows 经 COM、macOS 经 osascript 执行
- 输出命名兼容 SCM 预处理上传：Excel 含 Hash 列时输出 `{hash}-{序号}.png`，可直接在 SCM「预处理上传」入口批量上传挂单
- 支持进入首层嵌入式 PSD/PSB 智能对象，按 Excel 字段更新其中的文字并切换具体图层显隐
- 支持把普通像素层或 PNG/JPEG 图片智能对象配置为图片目标，按 Excel 值从外部素材目录映射图片并替换
- 支持铝板画订单自动识别：按 SKU + 严格方向尺寸匹配平铺 PSD/PSB，缺模板订单单独列出
- 支持 AI 生成模板字段/图层映射建议，用户审核后保存模板档案并复用；年份、姓名等仍按每条订单动态替换
- AI 服务配置保存在项目根目录 `.env`（不会被 Git 或源码打包包含）；导入订单后默认输出到订单 Excel 所在目录

## 环境要求

- Windows 或 macOS，已安装 **Photoshop CC 2018+**
- **模版用到的字体需先安装到系统**（缺字体时 Photoshop 会静默用替代字体渲染，输出需人工核对）。把字体文件放进模板库（任意子文件夹）即可：每次扫描模板库时会自动安装缺少的字体到当前用户字体目录；开始生成前若装了新字体，程序会正常退出 Photoshop 让字体生效（有未保存文档时等用户处理）
- Python 3.10+（或使用打包好的 exe，见下文）
- macOS 首次运行需在「系统设置 → 隐私与安全性 → 自动化」允许终端/本工具控制 Photoshop（会弹 Apple Events 授权框，点允许）

## AI 配置与模板审核

在应用内点击“AI 设置”：填写中转站地址和 API Key，点击“拉取模型”，勾选模型并通过上移/下移设置回退顺序，最后点击“保存到 .env”。配置写入项目根目录 `.env`（该文件已被 Git 和源码打包排除）：

```dotenv
PSD_RENDER_AI_BASE_URL=https://your-relay.example/v1
PSD_RENDER_AI_API_KEY=your-api-key
PSD_RENDER_AI_MODELS=gpt-5.5,gpt-5.6-terra,glm-5.3
```

铝板画订单按单分析：订单字段都已被模板规则覆盖时直接出图、不调用 AI；有新字段（或新模板的第一单）时，把这一单的定制文案交给 AI 映射到图层，程序检查通过即自动启用，不通过才进入人工审核（订单行「查看审核」或「审核待审核模板」）。未配置 AI 或额度用完时用本地规则兜底。「模板库管理」里的「删除内置绑定」只删除审核档案，不会删除 PSD 文件。详见 [铝板画自动出图实施方案.md](铝板画自动出图实施方案.md) 9.6。

## 启动

一键启动。每次启动自动检查环境，正常时不到 1 秒就起窗口：

- 没有 Python 3.10+：询问后自动安装到当前用户（Windows 用系统自带的 winget，macOS/Linux 用 [uv](https://astral.sh/uv)），不需要管理员权限
- `.venv` 不存在、创建被中断或从别的电脑拷来跑不起来：自动重建
- 依赖缺失或 `requirements.txt` 有变化（`.venv/.requirements.sha256` 记录上次安装时的校验值）：自动重装；官方源失败时依次换清华、阿里镜像；离线但旧依赖可用时照常启动
- 没检测到 Photoshop：只提示，不阻止打开（可以先审核模板）



- **macOS**: 在访达中双击 `启动.command`（首次若提示“无法验证开发者”，右键 → 打开 一次即可）；也可在终端里 `./start.sh`
- **Linux**: 终端里 `./start.sh`（或 `bash start.sh`）
- **Windows**: 双击 `run.bat`

程序只允许单开，已在运行时再启动会弹窗提示并退出。

也可手动启动：

```bash
cd plugin-psd-render
pip install -r requirements.txt
python main.py
```

## 模版制作约定（给设计师）

1. **定制文字图层的图层名 = Excel 列名**（如图层命名为 `姓名`、`日期`、`祝福语`），其余图层不受影响
2. 按约定放入模版目录：

```
模版目录/
├── 51052004/                    ← 目录名 = SKU
│   ├── 父亲节卡片.psd            ← 默认模版
│   ├── 父亲节卡片-[红色].psd     ← 变体模版（切换值=红色）
│   └── 父亲节卡片-[蓝色].psd
└── 51052005/
    └── 贺卡.psb                  ← 支持 .psb（大文档格式）
```

同一 SKU 可放多个模版，每行订单会逐个渲染，输出序号按文件名排序。

模版支持 `.psd` 与 `.psb` 两种格式。当模版文件超过 2 GB 或画布超过 30000 px 时，Photoshop 只能存为 PSB（Large Document Format）——两种格式二进制结构一致，psd-tools 解析与 Photoshop 渲染均原生识别，使用方式完全相同。

### 铝板画模板约定（2026-10-13 标准格式）

完整规范见 [铝板画自动出图实施方案.md](铝板画自动出图实施方案.md) 9.9，标准样板为 `HJ-lbh671010502(30×20cm）.psd`。要点：

- **文件名**：`SKU(宽×高cm).psd`，如 `HJ-lbh671010502(30×20cm).psd`；宽高顺序与订单一致，`30×20` ≠ `20×30`。旧写法 `（30-20）` 仍兼容。
- **顶层图层**：背景（只放场景）、`year` / `Man's Name` / `Woman's Name` 三个可编辑文字图层、可选的隐藏范围框 `Man's Name文本框范围`、显示的智能对象 `Characters' Look`。不要盖印整幅像素层，不要栅格化姓名/年份（否则该模板的订单会被跳过）。
- **人物素材**：`Characters' Look` 内 `Man素材` / `Woman素材` → 编号分类组（`4-Man's Beard`）→ 颜色/款式子组（`Brown`）→ 素材 `前缀_值`（`Beard_Brown_09` ↔ 订单值 `Brown_09`）。默认显示哪套都行：出图时整组先隐藏，再只打开订单选中的那一个；选 `No` 隐藏整组。不定制人物的订单只改文字，人物按 PSD 保存状态出图。
- **范围框**：出图时文字长了缩小到框内，短了放大到碰到框，最多放大到 1.3 倍；男女名字按两者中较小的比例一起缩放，保持一样大。

## Excel 约定

- 第一个 sheet，首行为表头
- 必须有 `SKU` 列（大小写不敏感）
- 可选 `Hash` 列：值为 8 位字母数字时启用 hash 命名模式（SCM 订单导出自带）；重复 hash 只保留首行
- 可选 `交易编号` 列：非 hash 模式下启用交易编号命名模式（输出 `{交易编号}.png`）；该列值为空的行跳过并记入失败报告
- 配置页可选填“图片命名 Excel 列”：单模板使用 `{列值}.png`，同一行多模板使用 `{列值}-1.png`、`{列值}-2.png`；留空时完全沿用原命名规则。列不存在、值为空或最终文件名重复时预检会阻止生成。
- 可选 `定制文案`（兼容 `定制信息`）列：每行使用换行分隔的 `key: value` 文案。相同或编辑距离相似度不低于 80% 的 key 自动归为同一字段；value 默认按中英文逗号、分号拆分，`Enter Kids' Name` 额外支持按空格拆分，拆分结果会去除名字首尾的中英文双引号，并按原始出现顺序逐一替换。拆分值数量与对应文字图层数量不一致时，预检会阻止生成
- `Enter Name + Character Code` 开头的定制字段使用姓名/角色编号专用规则，兼容 `Brett#7, Emma #1` 和 `Rosalind 13 Henry 10` 等格式。完整解析成功后按原始出现顺序导出为 `Name1, Character1, Name2, Character2...`，Character 列只保留数字；任一内容无法完整解析时整组回退普通 value 拆分规则
- 切换模版字段**按 SKU 配置**（配置页 SKU 清单里手填 Excel 列名）：该行此列的值用于挑变体模版（行值=红色 → 用 `模版-[红色].psd`，无匹配回退默认模版），配置随模版目录+SKU 记忆
- **其余所有列 = 图层名 → 替换文案**，空单元格跳过（保留模版默认文案）。`定制信息` 中匹配到的字段优先于同名独立列
- 如需按订单内容切换不同图层组（例如背景、版式、图案），可在「编辑配置」里选择一个 Excel 列名，并给同一父级下的候选图层填写对应列值。同一 Excel 列可控制多个父级规则，同一列值也可匹配并同时显示多个候选图层；未匹配时保留 PSD 默认显隐。
- 普通像素层和 PNG/JPEG 图片智能对象可配置图片替换：为该层选择 Excel 列和素材目录，扫描 `.png/.jpg/.jpeg` 后给每个文件填写“对应 Excel 值”。普通像素占位层使用 contain 等比缩放并居中；图片智能对象使用 Photoshop“替换内容”并保留原变换和效果。空单元格保留模板内容，缺少映射或素材时预检会阻止生成。
- 同一 SKU 有多个模板时，每个模板的配置区域可独立展开或折叠；可在配置较完整的模板标题旁点击“同步配置到其他模板”，预览后批量同步文字与图片配置。同步按完整图层路径匹配，同路径已有配置会覆盖，目标模板缺少或不支持的图层会忽略，目标模板独有配置保留。普通文字映射原本就在同一 SKU 内自动共享，候选组和智能对象内部的文字映射会按模板写入。
- 图层配置会标识智能对象。首层嵌入式 PSD/PSB 可展开，其内部可见文字图层默认按同名 Excel 列替换，也可填写其他列名；内部顶层及各图层组可按与主文档相同的规则配置 Excel 列和候选值，逐行切换具体图层显隐。图片、AI、PDF、链接型及更深层嵌套的智能对象只显示类型，不修改内容。

命名模式优先级：用户配置的图片命名列 > `Hash` > `交易编号` > 普通（SKU）。

## 界面流程

### 普通模板流程

1. 首页点击「导入订单 Excel」，这是唯一的订单输入入口；程序自动识别普通订单或铝板画订单模式。
2. 点击「模板库管理」才进入模板、图层和图片映射的高级配置；模板库支持任意子目录。
3. 在首页选择输出目录，按需展开“高级选项”填写命名列，最后点击「预检并生成」。（“导出预处理 Excel”已于 2026-10-13 作废，界面不再显示。）

### 铝板画自动流程

1. 选择模板库后，在首页“订单工作台”点击「导入订单 Excel」。
2. 系统识别 `SKU`、`尺寸`、`定制文案`，按 `SKU + 严格方向尺寸` 匹配模板。厘米尺寸优先；只有 inch 时自动换算。`30x20` 不会匹配 `20x30`。
3. 订单工作台显示可生成、待审核、缺模板和异常数量；点击状态可筛选订单。
4. 在缺模板订单上点击「导入模板」选择 PSD/PSB。文件名应包含 `SKU(宽×高cm)`，例如 `HJ-lbh671010502(30×20cm).psd`；程序校验后复制到模板库的“导入模板”目录并重新扫描。模板库支持任意子目录。
5. 新模板或新字段按订单自动分析：把这一单的完整定制文案交给 AI 映射到图层，程序检查通过就自动启用，不通过才需要点「审核待审核模板」人工处理（可修改姓名/年份写入的文字图层，留空表示不替换）。未配置 AI 或 AI 出问题时用本地规则兜底；AI 出问题会弹窗提示更换 API（写明原因）。只配置一个 API。API Key 只保存在程序目录的 `.env`。
6. 规则按 `SKU + 尺寸 + PSD 文件 + 图层结构签名` 复用：同一模板的后续订单字段都见过时，直接替换本单的年份、姓名、素材等数值，不再调用 AI。
7. 选择输出目录后点击「预检并生成」。只有“可生成”订单进入 Photoshop；缺模板、待审核或异常订单在预检中列出并跳过，不会阻塞其他订单，写入失败报告/日志。姓名/年份无法确定写入哪个文字图层的订单不会出图，原因写在失败报告里。

## 输出命名

| 模式 | 文件名 | 说明 |
|---|---|---|
| 自定义列 | `订单001.png` / `订单001-2.png` | 单模板使用 `{列值}.png`，多模板追加模板序号 |
| hash 模式 | `aB3kF9x2-1.png` | `{hash}-{序号}`，可直接传 SCM 预处理上传自动挂单 |
| 交易编号模式 | `T20260101A.png` | `{交易编号}`，空交易编号行跳过 |
| 普通模式 | `51052004-红色-3-1.png` | `{sku}[-字段值]-{行号}-{序号}` |

失败行汇总写入输出目录 `失败报告.csv`。

## 运行机制与异常处理

- 串行渲染（单 Photoshop 实例）：打开 PSD → 按完整路径切换图层显隐、替换文字和普通像素占位层图片 → SaveForWeb 导出 PNG24 → 关闭不保存（模版和素材文件均不被污染）
- 看门狗：先单独启动 Photoshop 并等它能响应（最多 5 分钟，冷启动不占出图时间）；出图时某一步超过 3 分钟没有进展、或单张超过 15 分钟判定卡死，强杀 Photoshop 并重试 1 次，报错写明卡在哪一步（多半是 Photoshop 弹了对话框）；仍失败记入失败报告并继续下一张
- 输出文件名防覆盖：同一批里文件名重复（不区分大小写，如 Hash 只差大小写、自定义命名列重复）时，后面那一单判失败，预检会提前警告
- 模版索引缓存：模版目录下 `.psd-render-cache.json`（比对 mtime+size），首次全量解析后秒级加载；「重新扫描」强制重建

## 打包成单个 exe（免装 Python 分发）

在 Windows 机器上：

```bash
pip install -r requirements.txt
flet pack main.py --name PSD批量生图 --add-data "render.jsx;."
```

产物在 `dist/` 下，双击即可运行（目标机器仍需安装 Photoshop 和字体）。

Windows 分支尚未实机验证。新电脑先双击 `Windows自检.bat`（macOS：`bash start.sh selfcheck`），把生成的 `自检结果` 文件夹发给维护人员；界面操作再按 `铝板画自动出图实施方案.md` 9.11 的验收清单走一遍。`pack.sh` / `pack.bat` 打的是源码 zip（不是 exe）。
