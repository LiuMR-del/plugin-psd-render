# PSD 批量生图 - 部署与使用说明

第一次使用只想照着做的，先看精简版 `操作步骤.txt`。

本文面向实际使用者，按“准备模版 -> 配置字段 -> 导入订单 -> 预检 -> 批量生成”的顺序说明操作。铝板画订单（按 SKU + 尺寸自动匹配模板）请直接看 5.5 和 14.2。

最后更新：2026-10-14

---

## 一、环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 或 macOS 12+ |
| Photoshop | CC 2018 及以上版本，需已激活 |
| Python | 需要 Python 3.10+；没有时双击启动文件会询问并自动安装 |
| 字体 | 模版用到的字体放进模版库即可，扫描时自动安装到当前用户（见 5.5）；也可以提前手动安装 |

字体缺失时 Photoshop 会静默使用替代字体渲染。因此每次“预检并生成”开跑前，程序会先安装模板库里的字体，再检查本次要生成的模板实际用到的字体本机是否都有（Photoshop 开着时直接问 Photoshop 能用哪些字体，最准；没开时按本机字体文件夹核对，不会为此启动 Photoshop）；缺的话弹窗列出“哪个模板、哪些图层、缺什么字体”，可选“关闭（去补充字体）”或“继续生成”。只装在旧电脑系统里、没放进模板库的字体，换电脑时不会跟过来，请把字体文件放进模板库文件夹。生成完成后应检查图片和 `生成日志.csv` 中的字体提示。

macOS 首次运行时会请求允许终端或本工具控制 Photoshop，请点击“允许”。如果误点拒绝，请前往：

`系统设置 -> 隐私与安全性 -> 自动化`

手动允许终端或本工具控制 Photoshop。

## 二、初次部署

1. 把源码包 `plugin-psd-render.zip` 解压到任意目录（路径可以有中文）。
2. 双击启动文件：Windows 双击 `run.bat`；macOS 在访达中双击 `启动.command`（首次提示“无法验证开发者”时右键 -> 打开一次）。
3. 第一次启动会自动准备环境（要联网，约 1~3 分钟）：没有 Python 3.10+ 时会询问是否自动安装（装到当前用户，不需要管理员权限），然后自动安装依赖，最后打开程序。
4. 需要 AI 分析时，在程序的「AI 设置」里填写，或把维护人员给的 `.env` 文件放进程序目录。

### 2.1 新电脑先做一次自检（推荐，尤其是 Windows）

- Windows：双击 `Windows自检.bat`；macOS：终端里在程序目录执行 `bash start.sh selfcheck`。
- 自检会先像正常启动一样准备环境，然后依次检查：依赖、自带测试、能否连上 Photoshop、用 Photoshop 新建一张测试图并按真实流程出图（中文路径、段落文字、长名字换行）、字体安装权限。会打开 Photoshop，但不会改模板库、配置和已打开的文档，也不会装字体。
- 用时约 1~5 分钟，结束后自动打开程序目录下的 `自检结果` 文件夹：`自检报告.txt`（结论在第 2 行）、`测试输出.txt`、`测试出图-中文名.png`。把整个文件夹发给维护人员即可；报告里有本机路径，不含 API Key。
- 测试图里左边应为两行 `Ruby` / `ClairRuby`，右边为放大的 `Ann`。

### 2.2 打包成 exe（可选，暂不推荐）

Windows 上也可以打成单个 exe（`flet pack main.py --name PSD批量生图 --add-data "render.jsx;."`，需先 `pip install "flet[all]==0.28.2"`），免装 Python。但每次更新都要在 Windows 上重新打包，且容易被杀毒软件误报，目前推荐直接用源码包 + `run.bat`。注意 `pack.sh` / `pack.bat` 打的是源码 zip，不是 exe。

## 三、日常启动与版本更新

一般不需要手动装环境：双击启动文件后会自动检查，缺 Python 时会询问是否自动安装（不需要管理员权限），缺依赖或依赖有更新时自动安装（官方源连不上会自动换国内镜像），没装 Photoshop 时只提示。第一次启动要联网，约 1~3 分钟；之后正常启动不到 1 秒。

每次启动：

- Windows：双击 `run.bat`，或双击打包好的 `PSD批量生图.exe`。
- macOS：在访达中双击 `启动.command`（首次提示“无法验证开发者”时右键 -> 打开一次），或在程序目录打开终端执行 `bash start.sh`。

程序只允许打开一个窗口；已在运行时再次启动会提示并退出。

收到新版代码包后：

1. 退出当前程序。
2. 解压新版 zip。
3. 将新版文件覆盖到原目录，保留 `.venv` 目录。
4. 重新启动程序。

新版 `requirements.txt` 有变化时，启动时会自动更新依赖，不用手动处理。使用 exe 的电脑需要重新执行打包步骤。

## 四、PSD/PSB 模版目录结构

普通模版按 SKU 分目录存放（铝板画模版是平铺在模版库里、文件名带尺寸的写法，见 5.5）：

```text
模版目录/
├── 51052004/                        <- 子目录名 = SKU
│   ├── 父亲节卡片.psd                <- 默认模版
│   ├── 父亲节卡片-[红色].psd         <- 变体模版，变体值 = 红色
│   └── 父亲节卡片-[蓝色].psd
├── 51052005/
│   └── 贺卡.psb                     <- PSB 大文档也支持
└── 51052006/
    ├── 正面.psd
    └── 背面.psd
```

规则：

1. 每个 SKU 一个子目录，目录名必须与 Excel 中的 SKU 值一致。
2. 默认模版命名为 `名称.psd` 或 `名称.psb`。
3. 变体模版命名为 `名称-[变体值].psd` 或 `名称-[变体值].psb`。
4. 同一 SKU 可以有多个默认模版，同一行订单会按文件名顺序逐个输出。
5. PSD 超过 2 GB 或画布超大时可使用 PSB，配置和生成方式相同。

程序扫描模版时会在模版根目录生成：

- `.psd-render-cache.json`：PSD/PSB 图层结构缓存。
- `.psd-render-thumbs/`：模版缩略图缓存。

这些文件可以保留。如果修改了 PSD 图层结构但界面没有更新，请点击“重新扫描”。重新扫描只重建模版图层缓存，不会清除已经保存的字段映射。

## 五、PSD 图层制作规则

### 5.1 普通文字替换

- 需要替换的文字图层，图层名默认对应 Excel 列名。
- 例如 PSD 文字图层名是 `姓名`，Excel 中有 `姓名` 列，该列内容会替换文字图层。
- Excel 单元格为空时不替换，保留 PSD 原文案。
- Excel 单元格中的换行会转换为 Photoshop 文本换行。
- 程序按完整图层路径替换，即使 PSD 中存在多个同名文字图层，也能分别处理。

如果图层名与 Excel 列名不同：

1. 在 SKU 卡片点击“编辑配置”。
2. 找到对应文字图层。
3. 在“文字列名”中填写实际 Excel 列名。
4. 点击“完成”。配置在输入时自动保存。

### 5.2 图片图层替换

当定制图案很多、不适合全部放进 PSD 时，可以把普通像素层或 PNG/JPEG 图片智能对象作为图片目标：

1. 普通像素占位层必须包含非空像素以确定替换范围；图片智能对象需要以 PNG/JPEG 为内容。
2. 在 SKU 卡片点击“编辑配置”，找到目标层并点击“图片替换”。
3. 填写 Excel 列名，选择素材目录，然后为扫描到的图片填写“对应 Excel 值”。
4. 点击“保存”。映射会与其他图层配置一起保存在用户配置文件中。

支持 `.png`、`.jpg`、`.jpeg`，素材目录中的子目录也会递归扫描。Excel 值按去除首尾空格后的完整内容精确匹配，不使用模糊匹配或文件名自动回退。

普通像素层生成时会按占位层边界等比缩放并居中，整张素材保持可见，宽高比不同时可能留空。图片智能对象使用 Photoshop“替换内容”，保留模板中已有的位置、缩放、旋转、蒙版、混合模式和图层效果。

Excel 单元格为空时保留模板原内容；有值但缺少映射、素材文件不存在或映射值重复时，预检会阻止整批生成。

普通像素层替换只保留占位层的层级位置、名称和当前显隐状态，不继承蒙版、图层样式、透明度、混合模式或剪贴关系；图片智能对象不受此限制。

同一 SKU 有多个模板时，每个模板的配置区域都可以独立展开或折叠。进入“编辑配置”后默认只展开第一个模板，其他模板保持折叠，以免 10 个或 20 个模板同时展开占用过多高度。

可以先配置图层最完整的模板，再点击该模板标题右侧的“同步配置到其他模板”：

1. 弹窗默认选中其他所有模板，可取消不需要同步的模板。
2. 展开目标模板可以预览每个文字或图片图层的“新增、覆盖、无需变更、忽略”结果。
3. 同步按完整图层路径匹配；普通像素层和 PNG/JPEG 图片智能对象之间可以同步。
4. 目标模板缺少同路径图层或图层类型不支持时直接忽略，不影响其他配置。
5. 普通文字图层映射按 SKU 保存，本来就会自动应用到同一 SKU 的所有模板；候选图层组和智能对象内部的文字映射会在确认后写入目标模板。
6. 确认后，同路径文字或图片配置会被源模板配置覆盖，目标模板独有配置会保留。
7. 取消预览不会保存任何更改；源模板中停用的图片配置也会按原状态同步。

### 5.3 字体要求

模版字体必须安装在运行电脑上，并确保 Photoshop 可以识别。PSD 能显示字体名称，不代表本机字体文件可用。

把字体文件（`.otf/.ttf/.ttc/.otc`）放进模版库任意文件夹即可：每次扫描模版库时，程序会把本机缺少的字体自动安装到当前用户字体目录（不覆盖已有字体，不需要管理员权限）；开始生成前如果装了新字体，会自动正常退出 Photoshop 让字体生效。Windows 上的自动安装尚未实机验证，装完请在字体列表里确认。

生成日志中如出现：

```text
替换后字体从 KGEmpireofDirt 变为 MyriadPro-Regular
```

说明 Photoshop 使用了替代字体。请安装正确字体，重启 Photoshop 后重新生成。

### 5.4 图层路径和命名建议

- 同一父级下的候选图层名称应尽量清晰，例如 `1`、`2`、`红色`、`蓝色`。
- 不要频繁修改已经配置过的组名和图层名；修改后旧配置路径会失效。
- 如果确实调整了图层结构，请重新扫描，并重新检查该 SKU 的配置。

### 5.5 铝板画模版制作规范（2026-10-13 与美工确认）

标准样板：`HJ-lbh671010502(30×20cm）.psd`。以后的铝板画模版都按这个格式做。

1. 文件名：`SKU(宽×高cm).psd`，例如 `HJ-lbh671010502(30×20cm).psd`。宽、高顺序要和订单尺寸一致，`30×20` 和 `20×30` 是两个不同的模版。括号建议统一用半角。旧写法 `HJ-lbh670908302（30-20）.psd` 仍然能识别。所有模版直接平铺放在模版库里即可（子文件夹也行），不需要按 SKU 建文件夹。

2. 主文档顶层图层：

| 图层 | 类型 | 要求 |
|---|---|---|
| `背景` / `background` | 像素或智能对象 | 只放场景，不能有人物，也不能有要替换的文字 |
| `year` | 文字图层，显示 | 年份。图层名或内容带 year、since、est 或年份数字。内容写成 `Since 1989` 时出图只换年份数字，`Since` 保留 |
| `Man's Name` | 文字图层，显示 | 男名，放左边 |
| `Woman's Name` | 文字图层，显示 | 女名，放右边，和男名不重叠 |
| `Man's Name文本框范围`、`Woman's Name文本框范围` | 形状，隐藏 | 名字最大可占范围。名字长了缩小到框内，短了放大到碰到框，最多 1.3 倍；要缩到约 77% 以下时在单词间空格处自动换成 2~3 行（不拆单词），取字最大的排法。两个名字始终一样大：一个名字太长要缩小时，另一个名字跟着缩到同样比例。文字用点文字、段落文字都可以 |
| `Characters' Look` | 智能对象，显示 | 换装人物 |

   不要做的事：
   - 不要盖印/合并出整幅像素层（会把默认人物盖在换装人物上面，或两层人物叠成重影）。
   - 不要隐藏 `Characters' Look`。
   - 不要把姓名、年份栅格化成图片（这种模版的订单会被标为“异常”并跳过）。

3. `Characters' Look` 内部结构：

```text
Man素材/                                <- 名称里要有 Man / Woman
  1-Chair/  Beige, Brown, Charcoal…     <- 分类组以「数字-」开头
  组 1/                                  <- 中间的普通组可以随便命名
    2-Man's Age Range And Skin Tone/  Aged Man 001…
    3-Man's Hair Color/  Black/ Blond/ Brown/ Gray/ Red/  -> Hair_Black_01…
    4-Man's Beard/       Black/ Blond/ Brown/ Gray/ Red/  -> Beard_Brown_09…
    5-Man's Glasses/  Glasses_01, Glasses_02
    6-Man's Drink/    Drink_01…
    7-Man's Top/      Hoodie/ Sweater/ T-shirt/  -> Top_Hoodie_03…
    8-Man's Pants/    Pants_01…
Woman素材/   结构同上（没有胡子）
```

4. 命名规则（程序靠图层名和订单值精确对应，改名时务必遵守）：
   - 分类组：`数字-字段名`，字段名与订单字段一致，例如订单 `Man's Beard` 对应组 `4-Man's Beard`。
   - 颜色/款式子组：名称就是订单值，例如 `Brown`、`Hoodie`、`T-shirt`。
   - 素材：`前缀_值`，程序去掉第一个下划线前的前缀再比较，忽略大小写和符号。例如 `Beard_Brown_09` 对应订单值 `Brown_09`，`Top_Tshirt_02` 对应 `T-shirt_02`。没有子组的素材直接用值命名：`Drink_02`、`Pants_05`、`Glasses_01`、`Aged Man 002`。
   - 同一分类组内素材名不能重复，否则该订单会失败。

5. 默认显示哪一套都可以。出图时程序会把整组先全部隐藏，再只打开订单选中的那一个。例如订单 `Man's Beard: Brown_09`：Gray 等其他颜色组隐藏，Brown 组只显示 `Beard_Brown_09`；订单选 `No` 时整组隐藏。订单不定制人物（Customize the Characters' Look: No）时只改文字，人物按 PSD 保存时的样子出图。

## 六、Excel 准备规则

### 6.1 基本列

- 程序读取第一个 sheet，第一行为表头。
- 必须有 `SKU` 列，大小写不敏感。
- 可选 `Hash` 列：8 位字母数字时启用 Hash 命名；无效或重复 Hash 行会跳过。
- 可选 `交易编号` 列：没有启用 Hash 模式时，使用交易编号命名；交易编号为空的行会跳过。
- 其他普通列可以作为文字替换、图层切换或图片替换字段使用。

### 6.2 定制文案/定制信息列

程序识别 `定制文案` 和 `定制信息` 两种列名。单元格内容使用换行分隔，每行格式为：

```text
key: value
```

示例：

```text
Enter Kids' Name: Alice, Bob
Choose Background: 11-Sky Blue
Date: 2026-07-23
```

拆分规则：

- value 默认按中文/英文逗号、中文/英文分号拆分。
- `Enter Kids' Name` 额外支持按空格拆分多个名字。
- 名字首尾的中文或英文双引号会被去除。
- 相同 key 或相似度不低于 80% 的 key 会归入同一字段。
- 拆分后的值始终保持原始出现顺序，不按其中的数字重新排序。
- 没有 `key:` 的内容会进入预检提示，不会作为有效字段使用。

### 6.3 姓名 + 角色编号专用格式

以 `Enter Name + Character Code` 开头的字段支持姓名和角色编号配对拆分。

支持格式：

```text
Enter Name + Character Code: Brett#7, Emma #1
Enter Name + Character Code: Rosalind 13 Henry 10
```

解析后得到以下字段，可作为文字列名使用：

| Name1 | Character1 | Name2 | Character2 |
|---|---|---|---|
| Brett | 7 | Emma | 1 |

注意：

- 姓名与角色编号始终保持配对。
- 输出顺序与原始定制文案中的出现顺序一致。
- Character 列只保留数字，不保留 `#`。
- 如果任意一项无法完整解析，整组内容会回退为普通 value 拆分，避免姓名和编号错位。

## 七、订单导入

首页只有一个订单入口：**导入订单 Excel**。导入后直接预检和出图，不需要先导出预处理 Excel（该功能已于 2026-10-13 作废并从界面移除）。

1. 选择模板库，等待扫描完成；模板可位于模板库任意层级子目录。
2. 如需高级文字、图层切换、图片替换配置，进入“模板库管理”编辑。
3. 在首页点击“导入订单 Excel”，选择要生成的原始 `.xlsx` 文件。输出目录会默认设为订单 Excel 所在目录，可手动修改。
4. 点击“预检并生成”。
   只想生成其中几张时，先在订单明细里勾选这些“可生成”订单，按钮会变成“预检并生成选中 N 条”；不勾选则生成全部可生成订单。

原始文件中的 `定制文案/定制信息` 会在生成过程中直接解析；没有此类内容的普通订单也可直接生成。修改了订单 Excel 后，在首页重新导入即可。

## 八、切换变体模版

当同一 SKU 有多个变体模版时，在 SKU 卡片的“切换模版字段”中填写 Excel 列名。

示例目录：

```text
51052004/
├── 贺卡.psd
├── 贺卡-[红色].psd
└── 贺卡-[蓝色].psd
```

“切换模版字段”填写 `颜色` 后：

| Excel 颜色值 | 使用模版 |
|---|---|
| 红色 | 贺卡-[红色].psd |
| 蓝色 | 贺卡-[蓝色].psd |
| 空值或未匹配值 | 回退默认模版 贺卡.psd |

如果没有匹配到变体，但成功回退默认模版，任务页面和 `生成日志.csv` 会记录提示。如果没有默认模版，该行会失败。

## 九、主文档图层和图层组切换

图层切换用于根据某个 Excel 值，在同一父级下显示匹配的候选图层或候选图层组。同一 Excel 列可以控制多个父级规则；同一规则内多个候选填写相同列值时，这些候选会同时显示。

### 9.1 配置步骤

1. 找到 SKU，点击“编辑配置”。
2. 展开需要控制的父级图层组。
3. 打开该组的“切换组内图层”。
4. 在右侧填写用于切换的“Excel 列名”。
5. 给同一父级下的候选图层填写“对应列值”。
6. 点击“完成”。

示例：

```text
背景色/                         <- 切换列：Choose Background
├── Yellow                     <- 对应列值：黄色
├── Blue                       <- 对应列值：蓝色
└── White                      <- 对应列值：白色
```

当 Excel 中 `Choose Background=蓝色` 时，程序显示 `Blue`，隐藏同级的 `Yellow` 和 `White`。

### 9.2 匹配规则

- Excel 值必须与“对应列值”完全一致。
- Excel 值为空：不执行该组切换，保留 PSD 默认显隐。
- Excel 值未匹配：不执行该组切换，保留 PSD 默认显隐，并写入预检和生成日志。
- 同一条切换规则中，一个列值可以对应多个候选项；命中时这些候选项会同时显示。
- 每个开启的父级切换规则都会独立匹配。即使另一个组已配置同样的值，当前组缺少该值仍会产生警告。

### 9.3 候选组内文字替换

如果候选图层组中还包含文字图层，可以给内部文字配置“文字列名”。程序只替换当前匹配候选组中的文字。

示例：

```text
文案/                           <- 切换列：Number of Family Members
├── 4/                          <- 对应列值：4
│   ├── William                 <- 文字列名：Name1
│   ├── Life                    <- 文字列名：Name2
│   └── Mary                    <- 文字列名：Name3
├── 5/                          <- 对应列值：5
└── 6/                          <- 对应列值：6
```

当 `Number of Family Members=4` 时，只显示 `文案/4`，并替换其中已映射的文字。

## 十、嵌入式智能对象配置

当前版本支持进入首层嵌入式 PSD/PSB 智能对象，替换其内部文字并切换内部图层。

### 10.1 支持范围

支持：

- 主文档中的首层智能对象。
- 智能对象内容为嵌入式 PSD 或 PSB。
- 智能对象内部的文字图层、顶层图层组和各级图层组切换。

暂不支持：

- 链接型智能对象。
- 内容为图片、AI 或 PDF 的智能对象。
- 智能对象内部再次嵌套的智能对象。

界面会显示智能对象类型和不可编辑原因。

### 10.2 配置内部文字

1. 在 SKU 卡片点击“编辑配置”。
2. 找到橙色标识的智能对象并展开。
3. 继续展开内部图层组。
4. 找到文字图层。
5. 在“文字列名”中填写 Excel 列名。

“文字列名”留空时，默认使用内部文字图层名匹配 Excel 列。

### 10.3 切换智能对象内部图层

操作方式与主文档一致：

1. 展开智能对象。
2. 找到需要控制的内部父级组。
3. 打开“切换组内图层”。
4. 填写 Excel 列名，例如 `Character1` 或 `Choose Background`。
5. 给每个内部候选图层填写“对应列值”。

如需切换智能对象内部的顶层图层组，打开“按字段切换智能对象顶层图层”，再填写 Excel 列名和各顶层候选值。

示例：

```text
智能对象：人物
└── 小人/组 1/                   <- 切换列：Character1
    ├── 1                       <- 对应列值：1
    ├── 2                       <- 对应列值：2
    ├── 3                       <- 对应列值：3
    └── ...
```

如果 Excel 中会出现 `1-15`，该父级下应按实际需求配置完整的 `1-15`。预检提示“存在未配置值”时，先根据警告中的智能对象和切换列定位，再检查该智能对象中所有使用该列的父级规则；不要只检查其中一组。

## 十一、共享智能对象的配置规则

PSD 中可能有多个图层引用同一份智能对象内容。例如：

```text
矩形 1885
智能图层组/矩形 1885 拷贝
```

虽然它们在主文档中是两个图层，但内部实际指向同一个智能对象。修改其中一个引用的内部文字或显隐，会同时影响另一个引用。

### 11.1 推荐配置方式

推荐只在其中一个引用上配置内部文字和图层切换，另一个引用保持未配置。程序会把有效配置合并为一次智能对象编辑任务。

也可以在两个引用上都配置，但必须遵守：

- 一边配置、另一边未配置：采用已配置的一边，不报错。
- 两边配置不同的内部图层：自动合并。
- 两边对同一内部图层设置相同结果：不报错。
- 两边对同一内部图层明确设置为不同结果：预检报“共享智能对象配置冲突”。

### 11.2 冲突示例

```text
引用 A：Choose Background=11-Sky Blue -> 显示 背景/11
引用 B：Choose Background=11-Sky Blue -> 显示 背景/1
```

程序会发现同一内部图层最终一边要求显示、另一边要求隐藏，并在预检中列出：

- 两个外部引用路径。
- 差异类型：图层显隐或文字替换。
- 具体内部图层路径。
- 引用 A 和引用 B 各自的结果。

处理方法：关闭其中一个引用上的重复切换配置，或者把两个引用的候选值映射调整为完全一致。

## 十二、配置保存、清除与缓存

### 12.1 配置如何保存

文字映射、图层切换、图片图层替换、智能对象配置和切换模版字段会自动保存。配置按以下范围区分：

`模版目录 + SKU + 模版文件 + 完整图层路径`

输出目录和“图片命名 Excel 列”属于全局配置，也会自动保存。重新启动程序后会继续使用上次填写的命名列；清空该输入框即可恢复原命名规则。

macOS 配置文件位于 `~/.plugin-psd-render/config.json`；Windows 位于 `%USERPROFILE%\.plugin-psd-render\config.json`。删除并重新解压项目目录不会删除该配置文件。

切换到其他模版目录或修改模版文件名后，不会自动套用旧配置。

### 12.2 清除映射

在 SKU 的“编辑配置”状态下，可以点击“清除映射”。该操作会删除当前 SKU 的：

- 普通文字字段映射。
- 主文档图层切换规则。
- 智能对象内部文字和图层切换配置。
- 普通像素层和图片智能对象替换配置。
- 切换模版字段。

清除操作不可撤销，不会影响其他 SKU，也不会修改 PSD 文件本身。

### 12.2.1 清理无效记录

“模板库管理”右上角的“清理无效记录”会先列出可清理的记录，勾选确认后才删除：

- 已不存在模板的档案：模板文件删掉或改了名，旧档案用不上了。移动过位置的模板库不算。
- 找不到的模板库的界面配置：config.json 里记的目录现在找不到。如果只是外接硬盘或网络盘没接上，不要勾选。默认不勾选。
- 其他模板库的界面配置：这些模板库还在，删了以后切回去要重新配置，默认不勾选。

只删程序自己生成的记录，不删 PSD/PSB、字体、订单和输出图片，也不删当前模板库的界面配置。删除不可撤销。没有对应模板的缩略图在每次扫描时自动删除，不用手动清理。模板库里有子目录读不到（权限或网络问题）时不会清理，会提示读不到的目录。

迁移到另一台电脑：把整个模板库文件夹（包括隐藏文件 .psd-render-profiles.json）拷过去即可沿用已审核的档案；AI Key 在项目目录的 .env 里，需要单独拷贝。出图记录（生成日志.csv、失败报告.csv）只写在每次的输出目录里，每次出图覆盖，程序内部不保留历史。

### 12.3 什么时候需要重新扫描

以下情况建议点击“重新扫描”：

- 修改了 PSD/PSB 图层名称、层级或类型。
- 新增或删除了模版文件。
- 智能对象内部结构发生变化。
- 界面显示的图层树与 Photoshop 不一致。

仅修改 Excel、对应列值或文字列名时，不需要重新扫描。

## 十三、生成结果命名

命名模式优先级：

`用户配置的图片命名 Excel 列 > Hash > 交易编号 > 普通 SKU`

配置页的“图片命名 Excel 列”默认留空，此时行为与之前版本完全一致。需要自定义时填写 Excel 表头的完整名称：

- 一行只生成一个模板：单元格值为 `订单001`，输出 `订单001.png`。
- 一行生成多个模板：依次输出 `订单001-1.png`、`订单001-2.png`。
- 单元格值已经以 `.png` 结尾时不会重复追加扩展名。
- 文件名中的 `/ : * ? " < > |` 会自动替换为下划线。
- 配置列不存在、单元格为空、清理后的文件名无效或不同订单产生同名文件时，预检会阻止生成，避免覆盖已有结果。
- 配置自定义命名列后，Hash 无效/重复或交易编号为空不会再按旧命名模式跳过订单；图片命名完全以配置列为准。

| 模式 | 输出文件名示例 | 说明 |
|---|---|---|
| 自定义列 | `订单001.png` / `订单001-2.png` | 单模板直接使用列值，多模板追加模版序号 |
| Hash 模式 | `aB3kF9x2-1.png` | `{Hash}-{模版序号}.png` |
| 交易编号模式 | `T20260101A.png` | `{交易编号}.png` |
| 普通模式 | `51052004-红色-3-1.png` | `{SKU}[-变体值]-{Excel行号}-{模版序号}.png` |

注意：交易编号重复时会生成同名文件，后生成的文件可能覆盖前面的文件。预检会提示重复风险。

## 十四、完整操作流程

### 14.1 普通模板流程

1. 启动程序。
2. 选择模板目录并等待扫描完成。
3. 点击“导入订单 Excel”。
4. 确认输出目录；需要按 Excel 列命名时，在“高级选项”填写“图片命名 Excel 列”。
5. 点击“预检并生成”，查看预检结果：错误必须修复，只有警告时才可继续生成。
6. 打开输出目录检查 PNG、`生成日志.csv` 和可能生成的 `失败报告.csv`。

### 14.2 铝板画自动流程

点击应用右上角“AI 设置”，填写中转站 URL 和 API Key，点击“拉取模型”，勾选模型并用上移/下移调整回退顺序，再点击“保存到 .env”。已经配置过的，打开“AI 设置”时会自动拉取模型列表。只配置一个 API（2026-10-14 起取消备用 API）；中转站里各家模型（gpt、claude、gemini、豆包、glm、kimi 等）都按“地址 + Key + 模型名”调用，按需勾选即可，图像模型（如 gpt-image-2）不要选。配置会保存到项目根目录：

```dotenv
PSD_RENDER_AI_BASE_URL=https://your-relay.example/v1
PSD_RENDER_AI_API_KEY=your-api-key
PSD_RENDER_AI_MODELS=gpt-5.5,gpt-5.6-terra,glm-5.3
```

`.env` 不会被 Git 或源码打包包含。API Key 不写入用户配置、模板档案或生成日志。

1. 选择包含平铺 PSD/PSB 的模板目录（例如 `D:\铝板画`），模版按 5.5 命名，例如 `HJ-lbh671010502(30×20cm).psd`。
2. 在“订单工作台”点击“导入订单 Excel”。系统读取 `SKU`、`尺寸` 和 `定制文案`，并自动将输出目录设为订单 Excel 所在目录；PNG、`生成日志.csv` 和 `失败报告.csv` 默认与订单表同级保存，仍可手动修改。
3. 系统按 SKU + 严格方向尺寸匹配模板。订单优先使用 cm；没有 cm 时将 inch 换算。`30×20` 不会使用 `20×30` 模板。
4. 检查订单工作台中的“可生成、待审核、缺模板、异常”数量；点击状态可筛选订单行。
   - 可生成：可以直接出图。
   - 待审核：模板已匹配，但本单有模板规则还没见过的字段，正在或等待自动分析；分析没通过的需要人工审核。
   - 缺模板：模板库里没有这个 SKU + 尺寸的模板。
   - 异常：缺 SKU、尺寸看不懂，或模板的姓名/年份是图片（没有可编辑文字图层）。
5. 在缺模板订单上点击“导入模板”，选择对应 PSD/PSB。文件名必须包含 SKU 和尺寸，程序会校验后复制到模板库的“导入模板”目录并重新扫描；模板库支持任意子目录。
6. 待审核订单会自动逐单分析：把这一单的定制文案交给 AI 对应到图层，程序检查通过就自动变为“可生成”，以后同类订单直接复用规则、不再调用 AI；检查不通过的，点订单行的“查看审核”或顶部“审核待审核模板”，确认姓名/年份写入哪个文字图层（留空 = 不替换）后点“审核通过”。没配置 AI 时用本地规则兜底；AI 出任何问题（Key 无效、额度用完、模型不可用、连不上、返回内容不对）会弹窗“AI 的 API 出现问题，请更换 AI 的 API”并写明原因，同时改用本地规则兜底。弹窗同一次运行只出现一次，在「AI 设置」重新保存后恢复。
7. 规则只保存“字段 -> 图层”的对应关系；年份、姓名、颜色、人物样式等实际值始终从每条订单的定制文案读取。规则保存在模板库目录里，换了新模板库需要重新分析（旧库的审核结果不会带过来）。
8. 点击“预检并生成”。只有“可生成”订单进入 Photoshop；缺模板、待审核或异常订单在预检中列出并跳过，不会阻塞其他订单，明细写入 `失败报告.csv`。
   只想生成其中几张时，先在订单明细里勾选这些“可生成”订单，按钮会变成“预检并生成选中 N 条”；不勾选则生成全部可生成订单。

AI 中转站在右上角“AI 设置”里配置（见上方），只用一个 API。

## 十五、预检信息及处理方法

### 15.1 错误：会阻止生成

常见错误包括：

- 定制文案拆分数量与目标文字图层数量不一致。
- 一个定制 key 同时匹配多个字段，无法确定目标。
- 图层切换列不存在，或 Excel 值没有配置任何候选图层。
- 共享智能对象对同一内部图层产生相反显隐或不同文字结果。
- 图片替换列不存在、目标不是有效像素层、映射值重复、Excel 值未映射或素材文件缺失。

预检会显示 Excel 行号、SKU、模版；共享智能对象冲突还会列出具体差异路径。修复配置后再次点击“预检并生成”；修改了订单 Excel 时，先在首页重新导入。

铝板画订单不会因为个别订单出错而阻止整批：人物素材对不上（某个素材组不是正好显示 1 个）、模板里的人物智能对象被隐藏、姓名/年份找不到对应文字图层等问题只让这一单跳过，原因写入 `失败报告.csv`，其余订单照常生成。

### 15.2 警告：允许继续生成

常见警告及含义：

| 警告 | 含义和处理 |
|---|---|
| SKU 缺少模版 | 对应行会跳过；检查 SKU 目录名和 Excel SKU 值 |
| 切换模版字段不存在 | 检查配置的列名是否与 Excel 表头完全一致 |
| 图层切换列不存在 | 该切换规则不会生效；检查 Excel 列名 |
| 图层切换存在未配置值 | 某条父级切换规则缺少候选映射；补齐对应值或关闭不需要的规则 |
| 显隐目标不存在 | PSD 图层结构已变化；重新扫描并重新配置 |
| 文字字段没有对应 Excel 列 | 填写正确文字列名，或确认该文字无需替换 |
| Excel 列未被任何模版使用 | 仅表示当前配置没有使用该列，可按实际情况忽略 |
| 变体值未匹配 | 有默认模版时回退默认模版；没有默认模版时该行失败 |
| 交易编号重复 | 可能输出同名文件并覆盖，应修改交易编号或拆分输出目录 |

“存在未配置值”的检查以每一条父级切换规则为单位。例如同一个智能对象中有两个组都使用 `Character1`，其中一个组配置完整，另一个组只配置了值 `1`，Excel 出现 `7` 时仍会产生警告。此时应在配置中检查该智能对象里所有使用 `Character1` 的父级组。

## 十六、生成日志和失败报告

生成完成后，输出目录包含：

| 文件 | 说明 |
|---|---|
| `生成日志.csv` | 每行、每张图的完整记录，成功、失败和跳过都会写入 |
| `失败报告.csv` | 仅在存在失败或跳过行时生成，便于快速定位问题 |

`生成日志.csv` 会记录：

- Excel 行号、SKU、模版、输出文件和状态。
- 变体未匹配但回退默认模版。
- 图层切换未匹配并保留 PSD 默认显隐。
- 字体替换后的字体变化提示。
- 实际执行的图片替换目标、Excel 值和素材文件。
- Photoshop 渲染失败原因。

程序采用单 Photoshop 实例串行生成。生成前会先启动 Photoshop 并等它就绪（最多 5 分钟）；生成中某一步超过 3 分钟没有进展、或单张超过 15 分钟，会判定卡住，自动重启 Photoshop 并重试一次，日志里写明卡在哪一步（最常见的是 Photoshop 弹出了对话框，请看一眼 Photoshop 窗口）；再次失败会写入失败报告，然后继续处理后续订单。日志里每张图后面会显示用时。

同一批订单里输出文件名重复时（文件名不区分大小写，例如 Hash 只差大小写、自定义命名列有重复值），后面那一单不生成并写入失败报告，避免覆盖前一张；预检时会提前提示。

## 十七、常见问题快速排查

### 修改了 PSD，但界面还是旧图层

点击“重新扫描”。确认修改的是当前选择模版目录中的文件。

### 明明配置了某个值，预检仍提示未配置

同一智能对象或模版中可能有多条规则使用同一个 Excel 列。展开配置，逐一检查所有使用该列的父级组，而不是只检查其中一组。

### 共享智能对象配置冲突

两个主文档图层引用同一个智能对象，但对同一内部图层配置了不同结果。推荐只保留一个引用的配置，或统一双方映射。

### 文字没有替换

依次检查：

1. Excel 表头是否与文字列名一致。
2. 单元格是否为空。
3. 本次导入的订单 Excel 是否为最新文件。
4. 该文字是否位于当前未命中的候选组中。
5. 智能对象是否属于支持的首层嵌入式 PSD/PSB。

### 图片生成成功但字体不对

检查 `生成日志.csv` 的字体提示，安装正确字体，完全退出并重启 Photoshop 后重新生成。

### 修改了订单 Excel

程序不会自动重新读取。修改后在首页重新点击“导入订单 Excel”选择这个文件。

### 铝板画订单明明有模板，却显示“缺模板”

1. 检查模板文件名是否为 `SKU(宽×高cm).psd`，SKU 是否与订单完全一致（例如 `670915204` 和 `670915205` 是不同 SKU）。
2. 检查宽高顺序：订单 `30×40` 只匹配 `(30×40cm)`，不匹配 `(40×30cm)`。
3. 改名或新增模板后点击“重新扫描”。

### 铝板画订单显示“异常”：模板没有可编辑的文字图层

模板里的姓名/年份是图片，程序没法替换，为避免出带示例姓名的错图而跳过。请美工按 5.5 把姓名/年份做成文字图层。

### 铝板画出图人物不对，或人物有重影

先在 Photoshop 里打开该模板检查：
- `Characters' Look` 是否被隐藏（订单要求换装时，程序发现它被隐藏会直接判失败，失败报告里写明“人物智能对象是隐藏的”）。
- 是否多了一张盖印/合并出来的整幅像素层（盖在换装人物上会导致人物换不掉；把隐藏的换装人物打开后又会和它叠成重影）。
- 素材图层名是否符合 5.5 的命名规则。

修好模板后重新扫描、重新出图。
