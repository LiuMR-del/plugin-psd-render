# PSD 批量生图 - 使用说明

- 第一次用、只想照着做：看 `操作步骤.txt`（精简版）。
- 让 AI 编程助手帮你安装或更新：把 `AI安装与更新指令.md` 里对应的一段复制给它。
- 本文是完整说明：怎么用、程序按什么规则出图、出了问题怎么查。

最后更新：2026-10-14

---

## 一、这个工具做什么

导入订单 Excel → 按「SKU + 尺寸」找到对应的铝板画 PSD 模板 → 让 Photoshop 换上订单里的姓名、年份和人物造型 → 批量导出 PNG。

订单表同时有 `SKU`、尺寸（`尺寸` / `规格` / `Size` 等）、`定制文案`（或 `定制信息`）三列时，程序自动按铝板画流程处理。本文正文讲的都是这个流程。

不满足这个条件的表格会走「普通模板流程」（按 SKU 文件夹找模板、手动配置字段）。这个流程目前没有在用，说明放在文末附录。

---

## 二、环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 或 macOS 12+ |
| Photoshop | CC 2018 及以上，已激活。先手动打开一次，把登录、更新等弹窗关掉 |
| Python | 3.10+。没有的话，启动脚本会询问并自动安装到当前用户（不需要管理员权限） |
| 字体 | 把模板用到的字体文件放进模板库文件夹，程序会自动安装（见 6.5） |

macOS 第一次运行时，系统会问是否允许终端或本工具控制 Photoshop，点“允许”。误点了拒绝，到「系统设置 → 隐私与安全性 → 自动化」里打开。

## 三、安装、更新与 AI 设置

### 3.1 安装

两种方式任选：

- **用 AI 编程助手（推荐）**：把 `AI安装与更新指令.md` 的「一、首次安装」整段复制给它。它会从 GitHub 下载程序、准备环境、跑自检、启动程序，最后告诉你还要填什么。
- **手动**：把程序包 `plugin-psd-render.zip` 解压到固定位置（如 `D:\PSD批量生图`，路径可以有中文；不要放在 `C:\Program Files` 下）。Windows 双击 `run.bat`，macOS 双击 `启动.command`（第一次提示“无法验证开发者”时，右键 → 打开）。

第一次启动要联网，约 1~3 分钟：自动建运行环境、安装依赖（官方源连不上会自动换国内镜像），然后打开程序。之后正常启动不到 1 秒。

### 3.2 新电脑先跑一次自检（推荐）

- Windows 双击 `Windows自检.bat`；macOS 在程序目录执行 `bash start.sh selfcheck`。
- 自检会准备环境，然后检查：依赖和自带测试、能否连上 Photoshop、用 Photoshop 新建一张测试图按真实流程出图（中文路径、段落文字、长名字换行）、字体安装权限。会打开 Photoshop，但不会改模板库、配置和已打开的文档，也不会装字体。
- 约 1~5 分钟。结束后会自动打开 `自检结果` 文件夹：结论在 `自检报告.txt` 第 2 行。测试图里左边应为两行 `Ruby` / `ClairRuby`，右边为放大的 `Ann`。有问题就把整个 `自检结果` 文件夹发给维护人员（里面有本机路径，不含 API Key）。

### 3.3 日常启动

Windows 双击 `run.bat`，macOS 双击 `启动.command`。程序只能开一个窗口，已经开着时再启动会提示并退出。

### 3.4 更新到新版本

- **用 git 安装的**：把 `AI安装与更新指令.md` 的「二、更新」复制给 AI 编程助手。
- **用 zip 包的**：先关掉程序，把新版 zip 解压后覆盖到原目录。原目录里的 `.venv`（运行环境）和 `.env`（AI 配置）会保留，新包里没有这两个文件夹/文件。

依赖有变化时，下次启动会自动更新，不用手动处理。

### 3.5 AI 设置

AI 只用来分析“模板规则还没见过的订单字段”该对应到哪个图层（见 4.5）。不配置 AI 也能出图，只是遇到新字段时需要人工审核的会多一些。

1. 点程序右上角「AI 设置」，填写中转站的「AI 服务地址」和「API Key」。
2. 点「拉取模型」，在「中转站可选模型」里勾选要用的模型，用箭头调整顺序：第 1 个失败时依次换下一个。中转站里各家模型（gpt、claude、gemini、豆包、glm、kimi 等）都可以选；图像模型（如 `gpt-image-2`）不要选。
3. 点「保存到 .env」。

- 只配置一个 API。已经配置过的，再打开「AI 设置」时会自动拉取模型列表。
- 地址、Key、模型保存在程序目录的 `.env` 文件里。Key 不会写进其他配置、模板档案或日志；`.env` 不会被上传到 GitHub，也不会打进 zip 包。
- AI 出任何问题（Key 无效、额度用完、模型不可用、连不上、返回的内容不对），程序会弹窗“AI 的 API 出现问题，请更换 AI 的 API”，并写明原因。弹窗里点「打开 AI 设置」可以直接更换。出问题期间程序改用本地规则，规则确定不了的订单进入人工审核。同一次运行只弹一次，重新保存 AI 设置后恢复提醒。

## 四、铝板画出图流程

### 4.1 准备模板库

模板库就是一个放 PSD/PSB 模板的文件夹。有多个品类时，建一个总文件夹，每个品类一个子文件夹，选总文件夹就能一次读到全部模板，不用来回切换：

```text
D:\模板库\          <- 选这个文件夹
├── 铝板画\
│   ├── HJ-lbh670908301(30×40cm).psd
│   └── HJ-lbh670908303(30×20cm).psd
└── 毛毯\
    └── SJS-mtfl680710101（50×60）.psd
```

- 模板在品类文件夹里直接平铺即可（再分子文件夹也行），不需要按 SKU 建文件夹。
- 文件名格式 `SKU(宽×高cm).psd`，模板内部按第五章的规范制作。
- 模板用到的字体文件（`.otf/.ttf/.ttc/.otc`）放在模板库里任意位置都可以。
- 同一个 SKU + 尺寸只能有一个模板。两个品类文件夹里有同名同尺寸的模板时，这类订单会标为“待审核”，提示里列出是哪几个文件。

### 4.2 选择模板库

在主界面「当前模板库」点「切换模板库」选择文件夹（有总文件夹就选总文件夹），等扫描完成。第一次扫描会读取全部模板并生成缩略图，较慢；之后只重读改过的模板。扫描时发现本机缺的库内字体会自动安装并提示。扫描完成后，状态行列出各品类的模板数，「模板库管理」里按品类分组显示。

以前单独选过某个品类文件夹（比如原来的 `D:\铝板画`）：把它整个移进总文件夹后改选总文件夹即可。程序会自动接收它里面审核过的规则和解析缓存，不用重新分析，也不会重新解析模板（状态行会显示“已合并子文件夹的审核档案 N 条”）。品类文件夹里的这些旧记录文件可以留着不管。

改了模板（改图层、新增或删除模板文件）后，点「当前模板库」旁的刷新按钮（重新扫描模板库）。

### 4.3 导入订单

在「订单工作台」点「导入订单 Excel」，选择订单表（读取第一个工作表，第一行为表头）。

- 输出目录默认设为订单表所在的文件夹，可在「选择输出目录」修改。
- 输出目录旁的「品类文件夹」自动取订单表文件名去掉开头的日期（`10.15毛毯.xlsx` → `毛毯`），可以改。同一文件夹里有多张不同品类的订单表时，分别导入、分别生成，各自进各自的品类文件夹。
- 订单表里有 `图片命名` 列时，程序会自动用它给输出图片命名（见第七章）。
- 修改了订单表后，要重新点「导入订单 Excel」，程序不会自动重读。

### 4.4 订单状态

导入后，「订单明细」里每单显示一个状态：

| 状态 | 含义 | 要做什么 |
|---|---|---|
| 可生成 | 模板已找到，所有字段都有规则 | 可以直接出图 |
| 待审核 | 模板已找到，但这一单有模板规则还没见过的字段 | 等自动分析（显示“排队中/分析中”）。分析没通过的显示「查看审核」，需要人工确认（见 4.5） |
| 缺模板 | 模板库里没有这个 SKU + 尺寸的模板 | 找美工要模板放进模板库后重新扫描，或点「导入模板」直接选 PSD |
| 异常 | 订单缺 SKU、尺寸看不懂，或模板里的姓名/年份是图片（没有可编辑的文字图层） | 点「查看原因」。模板问题要美工按第五章修改 |

「导入模板」会检查所选 PSD 的文件名是否带 SKU 和尺寸，然后复制到模板库的 `导入模板` 子文件夹并重新扫描。

### 4.5 自动分析与人工审核

- **规则复用**：每个模板记着“订单字段 → 图层”的对应规则（不记具体的名字、年份）。订单的字段都被规则覆盖时直接可生成，只换上这一单的内容，不调用 AI。
- **按单分析**：有新字段的订单（或新模板的第一单），程序把这一单的定制文案和模板图层信息交给 AI，一次只分析一单。程序检查 AI 的结果：通过就自动保存规则，订单变为可生成；不通过就进入人工审核。没配置 AI 或 AI 出问题时，用本地规则兜底。
- **人工审核**：点订单行的「查看审核」，或顶部的「审核待审核模板」。审核窗口列出没通过的检查项和 AI 被丢弃的建议，可以修改姓名、年份写入哪个文字图层（留空 = 不替换这个字段）。确认无误点「审核通过」；想让 AI 再试一次点「重新分析」。审核通过后，其余没有规则的字段记为“忽略”。
- 订单里“Other Special Requests”这类客户特殊要求有内容时，出图日志会提示“需人工确认”。
- 模板改了图层结构后，它原来的规则会作废，下一单会重新分析。

### 4.6 预检并生成

1. 只想出其中几张时，先在「订单明细」勾选这些“可生成”订单（也可以点「勾选全部可生成」「清空勾选」），按钮会变成「预检并生成选中 N 条」；不勾选就生成全部可生成订单。
2. 点「预检并生成」，程序先做预检：
   - **错误**会阻止生成，例如本次要生成的订单里图片命名列有空值或重复。按提示修改订单表后重新导入。
   - **警告**不阻止生成，例如待审核、缺模板、异常订单会列出来并跳过；某单人物素材或姓名年份对不上，也会提前列出并跳过这一单。
3. 确认后，程序检查字体（见 6.5）。缺字体会弹窗，可选「关闭（去补充字体）」或「继续生成」。
4. 开始生成。只有“可生成”订单进入 Photoshop，生成期间不要操作 Photoshop。Photoshop 卡住时（某一步超过 3 分钟没有进展，或单张超过 15 分钟），程序会自动重启它并重试一次，最常见的原因是 Photoshop 弹出了对话框。

### 4.7 检查结果

图片按 `输出目录/日期/店铺名/品类/图片名.png` 存放，例如 `10.15/示例店铺-us/毛毯/32-111-0000000-0000001-50x60.png`。日期是开始生成那天（月.日）；店铺取订单表的 `店铺名` 列，为空时放进 `未知店铺`。生成完点「打开输出目录」直接打开当天的日期文件夹。

日期文件夹里还有：

- `生成日志-品类.csv`（如 `生成日志-毛毯.csv`）：每张图的记录，图片列写的是 `店铺名/品类/图片名`。留意“字体”“需人工处理”“仍超出范围框”“需人工确认”等提示。
- `失败报告-品类.csv`：没生成的订单和原因。

**订单表标黄**：生成结束后（中途出错也会做），程序把这次全部生成成功的订单在原订单表里整行标黄，没生成或有失败的行不动。标之前先把原表复制到订单表旁边的 `备份` 文件夹（文件名带时间）。表格里的商品图片和其他格式不变。

- 标黄前请先在 WPS/Excel 里关掉这张订单表。表格开着时，Windows 上会标黄失败（日志会列出已生成的行号）；Mac 上标黄能写进去，但要关掉重新打开才看得到，而且不能在之前打开的窗口里保存，否则会把标黄覆盖掉。
- 同一张表再次生成时，已经标黄的行保持黄色。

## 五、铝板画模板制作规范（给美工）

标准样板：`HJ-lbh671010502(30×20cm）.psd`。以后的铝板画模板都按这个格式做。

### 5.1 文件名

`SKU(宽×高cm).psd`，例如 `HJ-lbh671010502(30×20cm).psd`。

- 宽、高顺序要和订单尺寸一致：`30×20` 和 `20×30` 是两个不同的模板。
- 括号建议统一用半角。旧写法 `HJ-lbh670908302（30-20）.psd`（全角括号、短横线）也能识别。
- 毛毯等按英寸卖的产品，文件名括号里直接写订单尺寸列的数字，不写单位，例如 `SJS-mtfl680710101（50×60）.psd` 对应订单尺寸 `50"x60"`。

### 5.2 主文档顶层图层

| 图层 | 类型 | 要求 |
|---|---|---|
| `背景` / `background` | 像素或智能对象 | 只放场景，不能有人物，也不能有要替换的文字 |
| `year` | 文字图层，显示 | 年份。图层名或内容带 year、since、est 或 4 位年份即可识别。内容写成 `Since 1989` 时，出图只换年份数字，`Since` 保留 |
| `Man's Name` | 文字图层，显示 | 男名，放左边 |
| `Woman's Name` | 文字图层，显示 | 女名，放右边，和男名不重叠 |
| `Man's Name文本框范围`、`Woman's Name文本框范围` | 形状，隐藏 | 名字最大能占的范围（见 6.3）。名称 = 文字图层名 + “范围”；名称写错时，程序会找唯一一个包住这段文字的框 |
| `Characters' Look` | 智能对象，显示 | 换装人物 |

姓名、年份用点文字或段落文字都可以；模板用到的字体文件放进模板库。

不要做的事：

- 不要盖印/合并出整幅像素层（会把默认人物盖在换装人物上面，或两层人物叠成重影）。
- 不要隐藏 `Characters' Look`。
- 不要把姓名、年份栅格化成图片（这种模板的订单会被标为“异常”并跳过）。

### 5.3 `Characters' Look` 内部结构

```text
Man素材/                                <- 名称里要有 Man / Woman
  1-Chair/  Beige, Brown, Charcoal…     <- 分类组以「数字-」开头
  组 1/                                  <- 中间的普通组可以随便命名
    2-Man's Age Range And Skin Tone/  Aged Man 001…
    3-Man's Hair Color/  Black/ Blond/ Brown/ Gray/ Red/  -> Hair_Black_01…
    4-Man's Beard/       Black/ Blond/ Brown/ Gray/ Red/  -> Beard_Brown_09…
    5-Man's Glasses/  Glasses_01, Glasses_02
    6-Man's Drink/    Drink_01…
    7-Man's Top/      Hoodie/ Sweater/ T-shirt/  -> Top_Hoodie_03…
    8-Man's Pants/    Pants_01…
Woman素材/   结构同上（没有胡子）
```

### 5.4 命名规则

程序靠图层名和订单值精确对应，改名时务必遵守：

- 分类组：`数字-字段名`，字段名与订单字段一致。例如订单 `Man's Beard` 对应组 `4-Man's Beard`。
- 颜色/款式子组：名称就是订单值，例如 `Brown`、`Hoodie`、`T-shirt`。
- 素材：`前缀_值`。程序去掉第一个下划线前的前缀再比较，忽略大小写和符号：`Beard_Brown_09` 对应订单值 `Brown_09`，`Top_Tshirt_02` 对应 `T-shirt_02`。没有子组的素材直接用值命名：`Drink_02`、`Pants_05`、`Glasses_01`、`Aged Man 002`。
- 同一分类组内素材名不能重复，否则该订单会失败。
- 默认显示哪一套都可以：出图时程序会把整组先全部隐藏，再只打开订单选中的那一个。

## 六、出图规则说明（程序怎么填）

### 6.1 尺寸匹配

- 订单「尺寸」列里有 cm 时用 cm 的数字（铝板画 `12×16inch(30×40cm)` → `30×40`）。
- 没有 cm 时直接用写的数字，不换算：`50"x60"`、`50“x60“`、`50x60`、`50×60`、`50-60` 都按 `50×60`，匹配文件名为 `SKU（50×60）.psd` 的模板（毛毯模板用这种写法）。
- 按数字找不到模板、而订单写的是 inch 时，再换算成 cm 找一次（`12×8 inch` → `31×20`）。
- 方向严格：订单 `30×20` 只匹配 `(30×20cm)` 的模板，不会用 `(20×30cm)`。
- SKU 必须和模板文件名里的完全一致。

### 6.2 姓名与年份

- **订单字段怎么认**：字段名含 year / date / est / since 的是年份；含 name 或 title 的是姓名，其中带 man / male / his 等的是男方，带 woman / female / her 等的是女方。
- **写进哪个图层**：已审核过的规则优先；否则按本地规则：1 个年份字段对 1 个年份图层；男名、女名对左右两个不重叠的姓名图层（左男右女）。判断不了的交给 AI，再不行就人工审核，不会乱猜。
- **检查**：每个有值的姓名/年份必须写进一个单独的、类型对得上的可见文字图层（年份不能进姓名图层，姓名不能进年份图层），否则这一单不出图并写明原因。
- **年份保留模板措辞**：模板年份图层原文是 `Since 1989`、`EST. 1995` 时，只把其中的年份换成订单的年份，前面的文字和排版保留。
- 模板里有文字图层没有对应的订单字段时，保持 PSD 原文。
- **其他文字**（Title、Initial、Sign、日期等）：由 AI 按订单判断写进哪个文字图层，检查通过就自动启用，以后同模板直接复用；判断不了的进审核，在审核里指定图层（留空 = 不替换）。

### 6.2.1 文字颜色与字体

- **怎么认**：字段名像 `Text Color`、`Font Color`、`Name Color` 的是文字颜色；`Font` 是字体。只写 `Color` 的（可能是毛毯底色）由 AI 判断。
- **颜色**：订单里写了色值就直接用，如 `Red (#E30200)`。只写颜色名的（如 `Light Pink`）由 AI 给出色值，或在审核里填写；同一个模板记住以后直接用。没有色值的订单不出图并写明原因。
- **字体**：直接用订单写的字体名。和模板字体同一种时不换；换成别的字体时保持模板的粗细（模板是粗体就用新字体的粗体）。本机没装这个字体时这一单失败，日志写明缺哪个字体，装好后重新生成。
- **改哪些文字**：默认改这一单写进去的姓名文字，年份不变；AI 判断出颜色只针对某段文字时只改那一段。

### 6.3 文字大小

- **有范围框的文字**：名字长了缩小到框内；短了放大到碰到框，最多放大到模板字号的 1.3 倍。单行要缩到模板字号约 77% 以下时，会试着在单词间的空格处换成 2~3 行，取字最大的排法；没有空格的长单词只缩小，不拆开。
- **男女名字一样大**：两个名字按其中较小的比例一起缩放。一个名字太长要缩小时，另一个也跟着缩到同样比例。
- **没有范围框的文字**：只在超出画布安全区（左右各留 4% 宽度）时缩小。
- 缩放后仍超出范围框的，日志里会提示需人工处理。

### 6.4 人物素材

- 订单的 CUSTOMIZE MAN / WOMAN 分区对应 `Man素材` / `Woman素材`；字段名对应编号分类组；字段值对应组内图层名（规则见 5.4）。
- 订单选 `No` 时整组隐藏。每个涉及的分类组最终必须恰好显示 1 个素材（`No` 为 0 个），对不上的这一单不出图并写明原因。
- 订单要换装、但模板里的 `Characters' Look` 是隐藏的，这一单直接失败。
- 订单不定制人物时（Customize the Characters' Look: No），只换文字，人物按 PSD 保存时的样子出图。

### 6.5 字体

- 每次扫描模板库时，程序把库里有、本机没有的字体自动安装到当前用户字体目录：不覆盖已有字体，不需要管理员权限。装了新字体后，开始生成前会自动正常退出 Photoshop，让新字体生效。
- 每次「预检并生成」开跑前，程序检查这次要用的模板里，显示的文字用到的字体本机是否都有。Photoshop 开着时直接问 Photoshop 能用哪些字体，最准；没开时按本机字体文件夹核对，不会为此启动 Photoshop。缺的话弹窗列出「哪个模板、哪些图层、缺什么字体」。
- 补字体：把字体文件放进模板库文件夹，再点「预检并生成」会自动安装。Adobe Fonts 的字体到 Creative Cloud 里激活。自己手动装的字体，要重启 Photoshop 才生效。
- 只装在旧电脑系统里、没放进模板库的字体，换电脑时不会跟过来。
- 选了“继续生成”，或者 Photoshop 换了字体时，日志里会有“字体提示”，例如“替换后字体从 KGEmpireofDirt 变为 MyriadPro-Regular”。

## 七、输出文件命名

主界面「高级选项」里的「图片命名 Excel 列」决定输出文件名。导入的订单表里有 `图片命名` 列、而这一栏是空的时候，程序自动填上 `图片命名`。

按图片命名列命名时：

- 一行只对应一个模板：直接用单元格的值，例如 `订单001.png`；对应多个模板时依次为 `订单001-1.png`、`订单001-2.png`。
- 单元格值已经以 `.png` 结尾时不会重复追加；文件名里的 `\ / : * ? " < > |` 和控制字符会替换成下划线。
- 本次要生成的订单里命名列为空、文件名无效，或不同订单产生同名文件时，预检报错并阻止生成，避免出错图或覆盖。待审核、缺模板、异常这些不会生成的订单不参与这项检查。

图片命名列留空、表里也没有 `图片命名` 列时，按以下顺序命名：

| 方式 | 条件 | 文件名 |
|---|---|---|
| Hash | 有 8 位字母数字的 `Hash` 列 | `{Hash}-{模板序号}.png` |
| 交易编号 | 有 `交易编号` 列 | `{交易编号}.png` |
| 普通 | 以上都没有 | `{SKU}[-变体值]-{Excel行号}-{模板序号}.png` |

不管哪种方式，同一批里文件名重复时（不区分大小写），只生成第一张，后面的判为失败，不会覆盖。预检会提前提示。

## 八、常见问题

**订单明明有模板，却显示“缺模板”**
1. 模板文件名是否为 `SKU(宽×高cm).psd`，SKU 是否和订单完全一致（`670915204` 和 `670915205` 是不同 SKU）。
2. 宽高顺序：订单 `30×40` 只匹配 `(30×40cm)`。
3. 改名或新增模板后，点「当前模板库」旁的刷新按钮（重新扫描模板库）。

**订单显示“异常”：模板没有可编辑的文字图层**
模板里的姓名/年份是图片，程序没法替换。为避免出带示例姓名的错图，这一单被跳过。请美工按第五章把姓名/年份做成文字图层。

**订单一直是“待审核”**
看状态是“排队中/分析中”还是「查看审核」。前者等它分析完；后者点开，确认姓名/年份写入的图层后「审核通过」。没配置 AI 时，新字段更多需要人工审核。

**弹窗“AI 的 API 出现问题”**
弹窗里写了原因。点「打开 AI 设置」更换地址、Key 或模型后保存。期间程序用本地规则兜底，不影响已经可生成的订单。

**开跑前弹窗“缺少字体”**
按弹窗里列出的模板和字体补字体（见 6.5），然后重新「预检并生成」。确实要先出图就点「继续生成」，这些文字会被 Photoshop 换成别的字体。

**年份前的 Since 不见了**
模板年份图层的原文里要带 `Since`（如 `Since 1989`），程序才会保留。把 Since 单独放在背景图里也可以。

**名字被缩小或换成了两行**
这是范围框在起作用（见 6.3）。两个名字会保持一样大，所以一个名字很长时，另一个也会变小。觉得范围不合适，让美工调整范围框的大小。

**出图人物不对，或人物有重影**
在 Photoshop 里打开该模板检查：`Characters' Look` 是否被隐藏；是否多了一张盖印/合并出来的整幅像素层；素材图层名是否符合 5.4。修好模板后重新扫描、重新出图。

**出图字体不对**
看 `生成日志-品类.csv` 里的字体提示，按 6.5 补字体，重新生成。

**Photoshop 卡住或报超时**
多半是 Photoshop 弹出了对话框，看一眼 Photoshop 窗口并关掉。程序会自动重启 Photoshop 并重试一次；仍失败的会写进失败报告，其余订单照常生成。

**改了 PSD，界面还是旧的**
点「当前模板库」旁的刷新按钮（重新扫描模板库）。确认改的是当前模板库里的文件。

## 九、程序保存的记录、换电脑与清理

| 记录 | 位置 | 换电脑时 |
|---|---|---|
| 模板规则（审核过的“字段 → 图层”，不含订单内容） | 所选模板库（总文件夹）里的隐藏文件 `.psd-render-profiles.json` | 随模板库文件夹一起拷贝（要包括隐藏文件） |
| 模板解析缓存、缩略图 | 所选模板库里的 `.psd-render-cache.json`、`.psd-render-thumbs/` | 不需要，会自动重建 |
| AI 地址、Key、模型 | 程序目录的 `.env` | 单独拷贝，或在新电脑的「AI 设置」重新填 |
| 界面配置（模板库、输出目录、命名列等） | `~/.plugin-psd-render/config.json`（Windows：`%USERPROFILE%\.plugin-psd-render\config.json`） | 不需要，铝板画流程不依赖它 |
| 出图记录 | 日期文件夹里的 `生成日志-品类.csv`、`失败报告-品类.csv` | 同一天同一品类再次出图会覆盖，程序内不留历史 |
| 订单表备份 | 订单表旁边的 `备份` 文件夹 | 每次标黄前备份一次，不自动删除 |

**换电脑**：拷贝整个模板库文件夹（含隐藏文件和字体文件）和 `.env`，在新电脑安装程序（第三章），选择模板库即可。模板库换了路径也能认出原来的规则（按 SKU + 尺寸 + 文件名匹配）。

**清理无效记录**：「模板库管理」里的「清理无效记录」会先列出可清理的记录，勾选确认后才删除：
- 已不存在模板的档案：模板文件删了或改了名，旧规则用不上了。
- 找不到的模板库的界面配置：如果只是外接硬盘或网络盘没接上，不要勾选。默认不勾选。
- 其他模板库的界面配置：删了以后切回去要重新配置。默认不勾选。

只删程序自己生成的记录，不删 PSD/PSB、字体、订单和输出图片，也不删当前模板库的界面配置和还在用的模板规则。删除不能撤销。模板库里有子文件夹读不到时不允许清理。

**删除内置绑定**：在「模板库管理」里可以删除某个模板的审核规则（PSD 文件保留），下一单会重新分析。

## 附录：普通模板流程（目前未使用）

订单表不满足铝板画条件（同时有 SKU、尺寸、定制文案三列）时，程序按普通模板流程处理：在「模板库管理」里按 SKU 手动配置每个模板的字段。目前所有订单都走铝板画流程，这部分仅备查。

### A.1 模板目录

```text
模板目录/
├── 51052004/                        <- 子文件夹名 = SKU（与 Excel 的 SKU 一致）
│   ├── 贺卡.psd                      <- 默认模板
│   ├── 贺卡-[红色].psd               <- 变体模板，变体值 = 红色
│   └── 贺卡-[蓝色].psd
└── 51052005/
    └── 贺卡.psb                      <- 超过 2 GB 用 PSB
```

同一 SKU 有多个默认模板时，一行订单按文件名顺序逐个输出。在 SKU 卡片的「切换模版字段」填一个 Excel 列名后，按该列的值选变体模板；没匹配上时回退默认模板，没有默认模板则该行失败。

### A.2 字段配置（模板库管理 → SKU 卡片 → 编辑配置）

- **文字**：文字图层名默认对应同名的 Excel 列；不同名时在「文字列名」里填 Excel 列名。单元格为空时保留 PSD 原文；按完整图层路径替换，同名图层也能分开处理。
- **图片替换**：把普通像素层（要有非空像素）或 PNG/JPEG 图片智能对象设为图片目标，填 Excel 列名、选素材目录、给每张素材填「对应 Excel 值」（完整内容精确匹配）。像素层按占位范围等比缩放居中；图片智能对象用“替换内容”，保留位置、蒙版和样式。
- **图层切换**：在父级组打开「切换组内图层」，填 Excel 列名，给候选图层填「对应列值」。命中的显示、同级其余的隐藏；值为空或没匹配上时保留 PSD 默认显隐（未匹配会写入预检和日志）。候选组内的文字也可以配置文字列名，只替换命中的那一组。
- **智能对象**：支持主文档首层的嵌入式 PSD/PSB 智能对象，可配置内部文字和图层切换；不支持链接型、图片/AI/PDF 内容和多层嵌套。
- **共享智能对象**：两个图层引用同一份智能对象时，建议只在一个引用上配置。两边对同一内部图层设置了相反结果，预检会报“共享智能对象配置冲突”。
- 「同步配置到其他模板」可把一个模板的配置按完整图层路径复制到同 SKU 其他模板（先预览再确认）。「清除映射」删除当前 SKU 的全部配置，不改 PSD。
- 配置按「模板目录 + SKU + 模板文件 + 图层路径」保存在 `config.json`；换模板目录或改模板文件名后不会自动套用。

### A.3 定制文案格式

`定制文案` / `定制信息` 列每行一条 `key: value`：

- value 按中英文逗号、分号拆成多个值；`Enter Kids' Name` 还按空格拆；首尾引号去掉；顺序保持原样。
- 相同或相似度不低于 80% 的 key 归为同一字段；没有 `key:` 的内容进入预检提示。
- 以 `Enter Name + Character Code` 开头的字段按「姓名 + 角色编号」配对拆成 `Name1, Character1, Name2, Character2…`，支持 `Brett#7, Emma #1` 和 `Rosalind 13 Henry 10` 两种写法；任何一项解析不了，整组回退为普通拆分，避免错位。

### A.4 预检

普通流程的预检错误会阻止整批生成，例如：定制文案拆分数量和文字图层数量对不上、图层切换列不存在、Excel 值没配置候选图层、图片映射缺失、共享智能对象冲突。警告不阻止生成，例如变体值未匹配、某列没被任何模板使用。
