# PSD 批量生图 - 操作步骤（精简版）

照着做就能出图。细节、出图规则和排错看 `使用说明.txt`。
以 Windows 为主，macOS 的不同之处单独注明。

最后更新：2026-10-14

---

## 一、每台电脑第一次使用前

1. 装好 Photoshop（CC 2018 及以上）并激活。先手动打开一次，把登录、更新之类的弹窗关掉，再退出。

2. 安装程序，两种方式任选：
   - 用 AI 编程助手（推荐）：把 `AI安装与更新指令.md` 里「一、首次安装」整段复制给它（仓库 https://github.com/LiuMR-del/plugin-psd-render ）。它会下载程序、准备环境、跑自检并启动，最后告诉你还要填什么。
   - 手动：把程序包 `plugin-psd-render.zip` 右键“全部解压缩”到固定位置，例如 `D:\PSD批量生图`（路径可以有中文）。
     - 不要放在 `C:\Program Files` 下（要管理员权限，程序写不了文件）；不要在压缩包窗口里直接双击运行。
     - 双击 `.bat` 时如果提示“Windows 已保护你的电脑”，点“更多信息” → “仍要运行”。也可以在解压前右键 zip → 属性 → 勾选“解除锁定”。
     - 然后双击 `Windows自检.bat` 跑一次自检：第一次会自动准备环境（要联网，约 1~5 分钟），缺 Python 时问是否自动安装，选“是”。结束后看 `自检结果\自检报告.txt` 第 2 行的结论；有失败项就把整个 `自检结果` 文件夹发给维护人员。

3. AI 配置（需要 AI 自动分析时）：
   - 把维护人员给的 `.env` 文件放进程序目录（和 `run.bat` 在同一层）；
   - 或者启动后点右上角「AI 设置」：填地址和 Key → 点「拉取模型」→ 在「中转站可选模型」里勾选（箭头调顺序，第 1 个失败时依次换下一个，图像模型不要选）→ 点「保存到 .env」。
   - `.env` 里有 Key，不要发到群里或别人电脑上。

4. 准备模板库：
   - 把整个模板库文件夹（如 `铝板画`）拷到本机，例如 `D:\铝板画`。
   - 要连同隐藏文件一起拷：`.psd-render-profiles.json` 里存着审核过的规则，拷过来就不用重新分析。（资源管理器“查看” → 勾选“隐藏的项目”可以看到它。）
   - 模板用到的字体文件（`.otf/.ttf`）都放进模板库文件夹，程序会自动安装。只装在旧电脑系统里的字体，换电脑不会跟过来。

macOS：手动安装时双击 `启动.command`（首次提示“无法验证开发者”时右键 → 打开）；自检在程序目录执行 `bash start.sh selfcheck`；系统问是否允许控制 Photoshop 时点“允许”。

## 二、每次出图

1. 启动：双击 `run.bat`（macOS 双击 `启动.command`）。程序只能开一个窗口。

2. 选择模板库：第一次点「切换模板库」选 `D:\铝板画`，等扫描完成（第一次较慢）。以后会记住。改了模板后，点「当前模板库」旁的刷新按钮重新扫描。

3. 导入订单：在「订单工作台」点「导入订单 Excel」，选当天的订单表。输出目录默认是订单表所在的文件夹，可以改；旁边的「品类文件夹」默认取订单表文件名（`10.15毛毯.xlsx` → `毛毯`），可以改。改了订单表要重新导入。

4. 看订单状态：
   - 可生成：可以直接出图。
   - 待审核：程序会自动逐单分析，通过后自动变成“可生成”，等一会儿即可。分析没通过的点「查看审核」，确认姓名/年份写进哪个文字图层后点「审核通过」。
   - 缺模板：模板库里没有这个 SKU + 尺寸的模板。找美工要模板，或点「导入模板」选 PSD。
   - 异常：点「查看原因」。订单缺 SKU/尺寸，或模板的姓名/年份是图片，需要人工处理，不会出图。

5. 出图：点「预检并生成」。
   - 只出其中几张：先勾选这些“可生成”订单，按钮会变成「预检并生成选中 N 条」。
   - 预检有“错误”时不能开始，按提示改订单表后重新导入；只有“警告”时可以「继续生成」。
   - 缺字体会弹窗提示（见第四节）。
   - 生成期间不要操作 Photoshop。装了新字体时程序会自动重启 Photoshop；Photoshop 卡住时会自动重启并重试一次。

6. 检查结果（在输出目录的当天日期文件夹里，如 `10.15`）：
   - 图片按 `店铺名/品类/` 分文件夹，逐张看 PNG：姓名、年份（含 Since）、人物是否正确。
   - `生成日志-品类.csv`：留意“字体”“需人工处理”“仍超出范围框”“需人工确认”的提示。
   - `失败报告-品类.csv`：没生成的订单和原因。
   - 订单表里生成成功的行已整行标黄，原表备份在订单表旁的 `备份` 文件夹。生成前请先关掉 WPS/Excel 里的这张表。

## 三、更新到新版本

- 用 AI 编程助手装的：把 `AI安装与更新指令.md` 里「二、更新」复制给它。
- 用 zip 包装的：先关掉程序（开着时更新，旧程序可能把审核记录写回旧内容），把新版 zip 解压覆盖到原程序目录，再双击 `run.bat`。原来的 `.venv` 和 `.env` 会保留，依赖有变化时会自动更新。

## 四、常见情况

| 现象 | 处理 |
|---|---|
| 订单明明有模板却显示“缺模板” | 模板文件名应为 `SKU(宽×高cm).psd`：SKU 和订单完全一致，宽高顺序和订单一致（30×20 和 20×30 不同）。改完点刷新按钮重新扫描 |
| 改了 PSD，界面还是旧的 | 点「当前模板库」旁的刷新按钮重新扫描 |
| 开跑前弹窗“缺少字体” | 弹窗列出哪个模板、哪些图层缺什么字体。点「关闭（去补充字体）」，把字体文件放进模板库文件夹，再点「预检并生成」会自动安装；Adobe Fonts 的字体到 Creative Cloud 里激活。确实要先出图就点「继续生成」，这些文字会被换成别的字体 |
| 弹窗“AI 的 API 出现问题” | 弹窗里写了原因。点「打开 AI 设置」更换地址、Key 或模型后保存；期间程序用本地规则兜底 |
| 年份前的 Since 不见了 | 模板年份图层的原文要带 Since（如 `Since 1989`），程序只换年份数字 |
| 名字被缩小或换成两行 | 范围框在起作用，两个名字保持一样大。觉得范围不合适，让美工调整范围框 |
| 人物不对或有重影 | 模板问题：`Characters' Look` 是否被隐藏、是否多了盖印的整幅像素层（见 `使用说明.txt` 第五章） |
| 其他问题 | 把 `失败报告-品类.csv`、`生成日志-品类.csv` 和截图发给维护人员 |
