# PSD 批量生图 - 操作步骤（精简版）

给第一次拿到程序包的人看：照着做就能出图。细节和排错看 `使用说明.txt`。
用 AI 编程助手（Claude Code 等）安装或更新更省事：把 `AI安装与更新指令.md` 里对应的一段复制给它即可（仓库 https://github.com/LiuMR-del/plugin-psd-render ）。
以 Windows 为主，macOS 的不同之处单独注明。

最后更新：2026-10-14

---

## 一、下载后先做的准备（每台电脑只做一次）

1. 确认电脑上装好了 Photoshop（CC 2018 及以上），并且已激活。先手动打开一次 Photoshop，把登录、更新之类的弹窗都关掉，再退出。

2. 解压程序包 `plugin-psd-render.zip`：
   - 右键 -> “全部解压缩”，解压到一个固定位置，例如 `D:\PSD批量生图`（路径可以有中文）。
   - 不要放在 `C:\Program Files` 下（要管理员权限，程序写不了文件）。
   - 不要在压缩包窗口里直接双击运行，一定要先解压。
   - 如果双击 `.bat` 时 Windows 提示“Windows 已保护你的电脑”或“安全警告”，点“更多信息” -> “仍要运行”。也可以在解压前右键 zip -> 属性 -> 勾选“解除锁定” -> 确定，再解压。

3. 放入 AI 配置（需要 AI 自动分析时）：
   - 把维护人员给的 `.env` 文件放进程序目录（和 `run.bat` 在同一层）；
   - 或者启动后在程序右上角“AI 设置”里填写 URL 和 Key -> 点“拉取模型” -> 在“中转站可选模型”里勾选（可用箭头调顺序，第 1 个失败时依次换下一个）-> 点“保存到 .env”。只配置一个 API；中转站里各家模型（gpt、claude、gemini、豆包、glm 等）都按“地址 + Key + 模型名”调用，直接勾选即可。
   - `.env` 里有 Key，不要发到群里或别人电脑上。

4. 准备模板库：
   - 把整个模板库文件夹（如 `铝板画`）拷到本机，例如 `D:\铝板画`。
   - 要连同隐藏文件一起拷：`.psd-render-profiles.json` 里存着已经审核过的规则，拷过来就不用重新分析。Windows 资源管理器里“查看” -> 勾选“隐藏的项目”可以看到它。
   - 模板库里的字体文件（`.otf/.ttf`）不用手动装，程序扫描时会自动安装。
   - 换新电脑时，只装在旧电脑系统里、没放进模板库的字体不会跟过来。建议把模板用到的字体文件都放进模板库文件夹。

5. 跑一次自检（推荐）：
   - 双击 `Windows自检.bat`。第一次会自动准备环境（要联网，约 1~5 分钟）：没有 Python 时会问是否自动安装，选“是”即可，不需要管理员权限。
   - 结束后会自动打开 `自检结果` 文件夹，看 `自检报告.txt` 第 2 行的结论。
   - 测试图 `测试出图-中文名.png` 里左边应为两行 `Ruby` / `ClairRuby`，右边为放大的 `Ann`。
   - 有失败项时，把整个 `自检结果` 文件夹发给维护人员。

macOS：解压后在访达中双击 `启动.command`（首次提示“无法验证开发者”时右键 -> 打开一次）；自检在程序目录的终端里执行 `bash start.sh selfcheck`；第一次运行时系统会问是否允许控制 Photoshop，点“允许”。

## 二、每次出图的步骤

1. 启动：双击 `run.bat`（macOS 双击 `启动.command`）。程序只能开一个窗口，已经开着时再双击会提示。

2. 选择模板库：选 `D:\铝板画`，等扫描完成。第一次扫描较慢；扫到新字体会提示，按提示重启 Photoshop。

3. 导入订单：在“订单工作台”点“导入订单 Excel”，选当天的订单表。输出目录默认就是订单 Excel 所在的文件夹，可以改。

4. 看订单状态：
   - 可生成：可以直接出图。
   - 待审核：程序会自动逐单分析，通过后自动变成“可生成”，等一会儿即可。分析没通过的，点“查看审核”，确认姓名/年份写进哪个文字图层后点“审核通过”。
   - 缺模板：模板库里没有这个 SKU + 尺寸的模板。找美工要模板，或点“导入模板”选 PSD。
   - 异常：订单缺 SKU/尺寸，或模板的姓名/年份是图片。需要人工处理，不会出图。

5. 出图：点“预检并生成”。
   - 只出其中几张：先勾选这些“可生成”订单，按钮会变成“预检并生成选中 N 条”。
   - 生成期间不要操作 Photoshop。Photoshop 卡住时程序会自动重启它并重试一次。

6. 检查结果（都在输出目录里）：
   - 逐张看 PNG：姓名、年份（含 Since）、人物是否正确。
   - `生成日志.csv`：每张图的记录，留意“字体”“需人工处理”“仍超出范围框”的提示。
   - `失败报告.csv`：没生成的订单和原因（只在有失败或跳过时才有）。
   - 修改了订单 Excel 后要重新点“导入订单 Excel”，程序不会自动重读。

---

## 三、收到新版程序包时

1. 关掉正在运行的程序（不关的话，旧程序可能把审核记录写回旧内容）。
2. 解压新版 zip，覆盖到原程序目录。保留原来的 `.venv` 文件夹和 `.env` 文件（新包里没有它们，直接覆盖不会删掉）。
3. 双击 `run.bat` 重新启动。依赖有变化时会自动更新。

## 四、常见情况

| 现象 | 处理 |
|---|---|
| 订单明明有模板却显示“缺模板” | 检查模板文件名 `SKU(宽×高cm).psd`：SKU 要和订单完全一致，宽高顺序要和订单一致（30×20 和 20×30 不同）。改完点“重新扫描” |
| 改了 PSD，界面还是旧的 | 点“重新扫描” |
| 开跑前弹窗“缺少字体” | 弹窗里列出哪个模板、哪些图层缺什么字体（Photoshop 开着时按 Photoshop 实际能用的字体核对，更准）。点“关闭（去补充字体）”，把字体文件放进模板库文件夹，再点“预检并生成”会自动安装；Adobe Fonts 的字体到 Creative Cloud 里激活。确实要先出图就点“继续生成”，这些图层会被 Photoshop 换成别的字体 |
| 出图字体不对 | 把字体文件放进模板库后重新扫描，按提示重启 Photoshop 再出图 |
| 人物不对或有重影 | 模板问题：检查 `Characters' Look` 是否被隐藏、是否多了盖印的整幅像素层（见 `使用说明.txt` 5.5） |
| 弹窗“AI 的 API 出现问题” | 弹窗里写了原因（Key 无效、额度用完、模型不可用、连不上等）。点“打开 AI 设置”更换地址、Key 或模型后保存；期间程序用本地规则兜底，确定不了的订单进人工审核 |
| 其他问题 | 把 `失败报告.csv`、`生成日志.csv` 和截图发给维护人员 |
